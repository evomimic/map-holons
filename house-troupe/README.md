# House Troupe packages

`house-troupe/` contains semantic package resources for MAP-stewarded
Dancers included in the standard MAP experience. It is neither a runtime
execution context nor a Cargo workspace.

Executable source remains in the workspace for its execution context. For
example, Space Navigator's current executable implementation remains under
`host/`; this directory contains only its separately loadable semantic package.

House Troupe membership is a stewardship and distribution designation, not a
runtime semantic relationship or a Dancer subtype.
